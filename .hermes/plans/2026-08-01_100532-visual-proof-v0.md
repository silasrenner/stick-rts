# Stick RTS V0 Visual Proof Implementation Plan

> **For Hermes:** Execute only this V0 proof in the isolated `agent/visual-proof` worktree. Do not alter simulation rules, economy, AI, collisions, or active commander work.

**Goal:** Demonstrate the approved Open Frontier visual language in the real Canvas RTS renderer: bright layered landscape, immediately distinct Sunmeadow and Bramblecrest presentation, and readable units/structures at gameplay scale.

**Architecture:** Keep the simulation keyed by `player`/`ai`; add a render-only presentation mapping that maps those teams to Sunmeadow League and Bramblecrest Wardens. Replace generic world drawing with deterministic procedural recipes made from crisp Canvas primitives. The world continues rendering directly at the existing resolution; this milestone does not introduce sprites, external runtime assets, a lower-resolution canvas, or new gameplay state.

**Tech Stack:** Vanilla ES modules, Canvas 2D, Node ESM check scripts, existing Chrome/CDP LAN-preview workflow.

---

## Boundaries

- **Render-only:** `/src/sim` remains untouched.
- **No copyrighted copying:** reference images guide mood, palette hierarchy, and shape language only.
- **No ambient RNG:** any repeated scenery is formulaic from world/camera position, not `Math.random` or simulation RNG.
- **No UX redesign:** preserve existing S11 build/UI layout; only use neutral palette tokens where necessary for harmony.
- **No content complete claim:** this is a visual proof and a user approval gate, not V1–V5 of the full art direction plan.

## Task 1: Add a testable visual-presentation contract (RED → GREEN)

**Files:**
- Create: `tools/visual-proof-contract-check.mjs`
- Create: `src/render/visualTheme.js`

1. Write `tools/visual-proof-contract-check.mjs` first. It imports `visualTheme.js` and asserts:
   - both simulation teams resolve to distinct named visual factions;
   - both faction palettes contain the required semantic colors (primary, accent, stone, timber, roof, banner, glow);
   - required unit and structure recipes exist;
   - the module imports no simulation code.
2. Run `node tools/visual-proof-contract-check.mjs`; expected RED: module-not-found.
3. Add the minimal pure `visualTheme.js` exports to pass.
4. Re-run the check; expected GREEN.
