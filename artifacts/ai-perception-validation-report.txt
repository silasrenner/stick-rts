LIVE PERCEPTION AND MEMORY

- Current live enemy information comes from the shared team-vision query surface.
- A visible mobile enemy creates a copied observation containing identity/type, last observed position, HP/state, flags, and lastSeenAt.
- When a mobile enemy leaves vision, its snapshot freezes. Hidden authoritative position, HP, state, direction, and death do not update the record.
- Re-entering vision refreshes the snapshot.
- Mobile memory remains valid while:

    matchElapsedTime - lastSeenAt <= difficulty.memoryStaleness

  Configured durations:
    Hard:   6 simulated seconds
    Medium: 15 simulated seconds
    Easy:   0 simulated seconds

- Expired mobile observations stop contributing to composition and estimated enemy power.
- Observed structures/turrets persist as frozen strategic observations. Their hidden HP/state cannot leak and re-observation refreshes them.
- Enemy base location remains known from configured match-start home coordinates, but hidden live base state is not read.

ASSESSMENT / COUNTER / THREAT CHANGES

- Existing counter relationships and utility architecture were not changed.
- Enemy composition is now current visible mobile enemies plus valid remembered mobile observations.
- Confirmed near-home threat uses currently visible enemies only; remembered positions cannot masquerade as a current contact.
- Existing enemy-power formulas now consume the visibility/memory-derived composition instead of global authoritative enemy state.
- Decision records expose visible and remembered composition, observations, lastSeenAt/memory age, remembered structures, known base, and derived threat/power context.
