Implemented
-----------
1. Configurable attack hysteresis
   - Launch: 8 combat units
   - Sustain: 5 combat units
   - New armies must reach 8 before attacking.
   - An established attack stays committed at 5+ combat; below 5 it rebuilds.
   - Confirmed near-home threats remain defensive overrides.

2. Attack standing-force reinforcement
   - Attack utility now positively values combat production.
   - Existing counter value still chooses warrior vs archer when valid visible/
     remembered enemy composition exists.
   - Build-cycle preference remains secondary.

3. Miner diminishing returns
   Miner-only economic need:
     reserveTarget = cheapest representative combat cost * 3
     reserveNeed = clamp((reserveTarget - gold) / reserveTarget, 0, 1)
     workforceNeed = max(0.25, 1 - miners / 8)
     economicNeed = reserveNeed * workforceNeed
   This is friendly-state only and not a miner cap. Zero-miner emergency remains.
