LIVE PERCEPTION MODEL

At each AI decision:

  authoritative world
    -> src/sim/vision.js getVisibleEnemyEntities(world, team)
    -> current visible snapshots + controlled memory update
    -> buildAiAssessment(...)
    -> unchanged goals / utility / commands / production

Hard no longer has globalVision: true. The AI-local CONFIG.AI_SIGHT_RANGE approximation is no longer used by the AI subsystem for enemy knowledge.

The shared simulation-owned vision query is the same current-visibility source used by Left/Right spectator presentation.

MOBILE MEMORY

Visible mobile-enemy snapshots include:
- id
- kind
- team
- x/y
- hp/maxHp
- state
- type/hero flags
- lastSeenAt

On loss of vision:
- The last visible snapshot is retained.
- Hidden authoritative position, HP, state, direction/facing, and death are not refreshed.
- Remembered mobile units contribute to composition only while fresh.

Expiration reuses existing difficulty.memoryStaleness:
- Hard: 6 simulated seconds
- Medium: 15 simulated seconds
- Easy: 0 simulated seconds

Validity rule:
  currentTime - lastSeenAt <= difficulty.memoryStaleness

Expired mobile observations are removed and stop contributing to composition and enemy-power estimates.

STRUCTURE AND BASE MEMORY

- Observed enemy structures, including turrets, persist in rememberedEnemyStructures.
- Hidden changing status remains frozen at the last observed snapshot.
- Re-observation refreshes the structure snapshot.
- Enemy core/base location remains known from match start using configured home coordinates.
- The known base record does not expose hidden live HP/state.

COMPOSITION / COUNTERS / THREAT / POWER

- Existing counter relationships and utility logic are unchanged.
- Composition now derives from currently visible mobile enemies plus unexpired remembered mobile observations.
- Structures and the base do not contribute to mobile composition.
- enemyNearHome now uses only currentlyVisibleEnemies; memory cannot impersonate confirmed current tactical threat.
- estimatedEnemyPower retains its existing formula but now uses visibility/memory-derived composition.
- friendlyPower remains fully authoritative for the AI's own team.
