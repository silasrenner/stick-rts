Economy / production integration
================================

Raven uses the ordinary economy legality and spending seam: it requires real gold and adds exactly its cost to goldSpent. It uses a separate temporary-action/cooldown slot, not the FIFO production queue. This is intentionally the smallest clean seam because Raven is not an army unit or structure: it does not consume queue capacity, population, or combat-production time, and cannot alter Hard buildIndex progression.

Vision and AI memory
====================

Raven writes only generic temporary descriptors into world.visionSources. Existing team-vision queries, Full/Left/Right spectator visibility, AI current observations, mobile memory expiry, and persistent observed-structure memory consume those descriptors normally. No Raven-specific visible-enemy, memory, composition, or AI information path was added.
