Exact V0 information formula
============================
currentEnemyCoverage = 1 when the current team-visible snapshot has enemy combat or a non-base enemy structure; otherwise 0.

informationStaleness = absent meaningful observation ? 1 : clamp(timeSinceMeaningfulEnemyObservation / 60, 0, 1)

scoutingNeed = clamp(0.60 * informationStaleness + 0.40 * (1 - currentEnemyCoverage), 0, 1)

Raw bounded inputs include current/remembered combat and structure counts, time since current contact, time since meaningful observation, and composition knowledge age. No input compares observation/memory with hidden enemy state.

Exact affordability and utility formula
=======================================
protectedCombatReserve = cheapestCombatCost * max(existing economic reserve target, max(0, attackLaunchCombatUnits - friendlyCombatUnits))
scoutingAffordability = clamp((gold - protectedCombatReserve) / RavenCost, 0, 1)
ravenUtility = 2.00 * scoutingNeed * strategicScoutingWeight[currentGoal] * scoutingAffordability

Goal weights: Recover 0.20, Build Army 1.00, Defend 0.50, Attack 1.00.

Candidate / feasibility behavior
================================
Raven is a generic { action: 'raven', kind: null } candidate. Existing Raven feasibility remains normal gold / active Raven / cooldown. Infeasible Raven is unscored; it is not a negative-utility hack. Raven only wins if its utility is strictly greater than the unchanged best normal-unit utility; ties preserve the unit. Raven selection calls buyRaven, never advances buildIndex, never consumes population, and never touches the unit FIFO.
